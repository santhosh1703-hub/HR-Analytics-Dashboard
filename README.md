# HR Analytics Dashboard

## Project Overview

An interactive HR Analytics Dashboard created using Tableau to analyze employee attrition and workforce trends.

## Tools Used

- Tableau
- Excel / CSV
- Data Analysis
- Data Visualization

## Key Analysis

- Employee Count
- Attrition Count
- Attrition Rate
- Active Employees
- Average Age
- Attrition by Gender
- Department Wise Attrition
- Number of Employees by Age Group
- Job Satisfaction Rating by Job Role
- Education Field Wise Attrition
- Attrition Rate by Gender for Different Age Groups

## Key Insights

- Total of **1,470 employees**, with **237 attrition** cases (**16.12% attrition rate**) and **1,233 active employees**
- Average employee age is **37**
- Male employees have higher attrition (**150**) than female employees (**87**)
- R&D (56.12%) and Sales (38.82%) account for most attrition; HR accounts for 5.06%
- Most employees fall in the **30-39** age range
- **Life Sciences** (89) and **Medical** (63) education fields have the highest attrition
- The **25-34** age group has the highest attrition (29.11%)

## Dataset

HR employee attrition data covering employee demographics, job roles, departments, education, and job satisfaction.

## Dashboard

Created an interactive Tableau dashboard to generate workforce and attrition insights from HR data.
